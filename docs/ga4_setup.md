# GA4 をつなぐ手順

Dolphin CREATE は、各会場の GA4 から LP・予約フォームの計測値を毎朝自動で取り込みます（読み取りだけ。GA4 の設定は変えません）。

## 1. 本部で一度だけ行うこと（サービスアカウントの用意）

1. Google Cloud でプロジェクトを1つ作り、「Google Analytics Data API」を有効にする。
2. 「IAM と管理 → サービスアカウント」でサービスアカウントを1つ作る（例：`dolphin-create-ga4`）。役割は付けなくてよい。
3. そのサービスアカウントの「鍵 → 鍵を追加 → JSON」で鍵をダウンロードする。
4. 鍵の中身を、公開先（Vercel）の環境変数 `GA4_SERVICE_ACCOUNT_JSON` に登録する。**鍵はメールやチャットで送らず、リポジトリにも入れない。**
5. あわせて `CRON_SECRET`（毎朝の自動取込用の合言葉。長いランダムな文字列）を登録する。

## 2. 会場ごとに行うこと

1. 会場の GA4 で「管理 → プロパティのアクセス管理 → ＋ → ユーザーを追加」を開き、上のサービスアカウントのメールアドレス（`…@….iam.gserviceaccount.com`）を **閲覧者** で追加する。Dolphin CREATE の ① の画面「GA4 の接続」にも、追加するメールアドレスを表示している。
2. 「管理 → プロパティの詳細」で **プロパティ ID（数字）** を確認する。`G-` で始まる測定 ID ではない。
3. Dolphin CREATE にマーケ・データ（Aさん）か施設管理者でログインし、その会場の「① Dolphinデータ連携 → GA4 の接続」にプロパティ ID を入れて「接続を保存」。
4. 「今すぐ取り込む」で過去の分（初期値は直近28日）を取り込む。以降は毎朝 6:00 に直近3日分を自動で取り直す。

## 3. 会場のサイトに設置するイベント

| イベント | いつ記録するか |
|---|---|
| `page_view` | ページを開いた（GA4 の標準） |
| `view_fair` | フェアの詳細ページを見た |
| `select_fair` | 「フェアを予約」ボタンを押した |
| `form_start` | 予約フォームに入力を始めた |
| `form_error` | 入力エラーが出た |
| `generate_lead` | 予約が完了した |

- 広告の URL には `utm_source`・`utm_medium`・`utm_campaign`・`utm_content`（＝広告ID）を付ける。Dolphin CREATE は `utm_content` で広告ごとに集計する。
- 氏名・メール・電話などの個人情報は GA4 に送らない。予約と来館・成約は、予約台帳の lead_id でつなぐ。
