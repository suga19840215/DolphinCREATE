# M2｜来館メイン顧客と TOP 広告の合致の補足（版：m2-2026-10-14）

入力は、1つの媒体について、その媒体から来館した客の匿名の集計（人数、多いクラスタ・年齢・エリア、重視している訴求軸と割合）と、その媒体に掲載している TOP 広告のキャッチコピーと、ビジュアル・キャッチの訴求軸、システムが分類で出した判定（合致／一部合致／不一致）です。

- 判定はシステムの結果を変えない。あなたは、その判定になった理由と、来館客に合わせるための改善案を出す。
- reason：判定の理由を、入力の数値（人数・割合）を引用して2〜3文で。
- visual_suggestion：ビジュアルをどう変えるとよいか（写すもの・雰囲気）を1〜2文で。会場にない設備・景色を描かせない。
- catch_suggestions：キャッチコピー案を3つ（全角20字以内）。1案1訴求。入力にない価格・特典・実績は書かない。
- 来館客の人数が少ないとき（30人未満）は、caution にその旨を書く。
